## 3D-printed-lock
A fully 3D-printed lock &amp; key, showcasing the mechanics of how they work. Made for HackClub's HalfLife event.

![A fully 3D-printed lock](https://github.com/he1ias/3D-printed-lock/blob/main/Final.png)

### How does it work?

Just like any other lock! With the correct key, the pins get pushed into the correct position and the barrel turns. Without it, the barrel is locked in place.

### What's the point?

To demonstrate the mechanics of how locks work.

### How can I build it myself?

Easy! `.STL` & `.STEP` files are located inside this repository which are ready to print!

For the print settings, I used SLA (resin) and a layer of 0.12mm to make sure the finer details of the key and pins was preserved. I also made sure the lock body itself was printed with its z-axis up, to preserve the small 1.6mm M2 screw holes.
